# Тестирование geometric_lib

Unit-тесты написаны на стандартном модуле `unittest` и лежат в папке `tests`:

- `tests/test_circle.py` — тесты `circle.area` и `circle.perimeter` (9 тестов);
- `tests/test_square.py` — тесты `square.area` и `square.perimeter` (9 тестов).

Ожидаемые значения посчитаны по формулам из [README.md](README.md). Код фигур при написании тестов не менялся.

## Запуск

Из корня репозитория:

```
python3 -m unittest -v
```

## Результаты

Всего 18 тестов, все пройдены (OK).
